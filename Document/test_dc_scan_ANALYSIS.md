# test_dc_scan 程序流程说明

## 程序概述

`test_dc_scan` 是一个用于测试 EtherCAT DC (Distributed Clock) 激活码的诊断工具。它通过完整的初始化序列和 CSP 模式测试，验证特定激活码配置下电机是否能正常工作。

## 总体架构

```
┌─────────────────────────────────────────────┐
│            主程序流程                        │
│  ┌────────┐  ┌────────┐  ┌─────────────┐  │
│  │初始化  │→│周期循环  │→│  结果输出   │  │
│  └────────┘  └────────┘  └─────────────┘  │
└─────────────────────────────────────────────┘
```

### 5. 关键算法

#### 5.1 状态机控制算法

```cpp
uint16_t low = status & 0x6f;  // 提取状态字低位
uint16_t ctrl;

if (low == 0x40) {
  ctrl = 0x06;              // Switch on disabled → Shutdown
} else if (low == 0x21 || low == 0x23 || low == 0x33) {
  ctrl = 0x0F;              // Ready → Enable operation
} else if (low == 0x27 || low == 0x37) {
  ctrl = 0x0F;              // Operation enabled
  enabled = true;
} else if (status & 0x0008) {
  ctrl = (toggle++ % 2) ? 0x06 : 0x80;  // Fault reset
}
```

#### 5.2 固定目标策略

```cpp
if (!enabled) {
  // 未使能时：跟随当前位置
  EC_WRITE_S32(target_position, position);
} else {
  // 已使能时：固定目标
  if (target == 0) {
    target = initial_pos + 1000;  // 只设置一次
  }
  EC_WRITE_S32(target_position, target);  // 持续写同一个值
}
```

#### 5.3 安全限位算法

```cpp
max_pos = max(max_pos, position);
min_pos = min(min_pos, position);

if ((max_pos - min_pos) > kSafetyTravelLimit) {
  safety_trip = true;  // 触发安全停止
  ctrl = 0x06;
}
```

### 7. 结果判定逻辑

```cpp
int32_t travel = max_pos - min_pos;
bool motor_moved = enabled && (travel > 10);

if (motor_moved) {
  结论: MOTOR_MOVED ✅
} else if (op_reached && enabled && bit12 == 0) {
  结论: BIT12_CLEAR ⚠️
} else if (op_reached && enabled) {
  结论: OP_BUT_IDLE ⚠️
} else {
  结论: NOT_WORKING ❌
}
```

## 性能特点

1. **实时性**：1ms 周期，使用 `clock_nanosleep` 精确定时
2. **健壮性**：无缓冲输出，异常时也能显示关键信息
3. **安全性**：内置限位保护和故障检测
4. **诊断性**：详细的日志输出和结果分析
