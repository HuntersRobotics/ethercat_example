# test_dc_scan 详细执行流程（0x0301 激活码）

## 完整执行流程 - 使用 0x0301 激活码

### 启动命令

```bash
./test_dc_scan 0x0301 1000000 5000
```

**参数说明**：
- `0x0301` - DC 激活码（16进制）
- `1000000` - DC 周期：1000000 纳秒 = 1 毫秒
- `5000` - 运行时间：5000 毫秒 = 5 秒

---

```

┌─────────────────────────────────────────────────────────┐
```

```
│    │                                                   │

│    • 0x0301 - 激活码（启用 Sync0）                     │
```

**0x0301 激活码含义**：
- Bit 0: 保留
- **Bit 1: 激活 Sync0** (SM2 输出)
- Bit 2: 激活 Sync1
- Bit 3+: DC 相关配置

## 关键成功因素

### 1. 正确的激活码 0x0301

```
ESI 文件值: 0x0300 ❌ 不工作
实际需要:   0x0301 ✅ 工作
```

### 2. 完整的状态机处理

```
Not Ready → Ready → Switched On → Operation Enabled
0x0000    0x0021   0x0023    0x1237
```

### 3. 固定目标策略

```cpp
// 只在第一次设置目标
if (target == 0) {
  target = initial_pos + 1000;  // 5940 + 1000 = 6940
}
// 持续写同一个目标（不是 position + 1000）
EC_WRITE_S32(target_position, target);
```

### 4. DC 周期性同步

```
每 1ms:
  1. 发送 Sync0 信号
  2. 电机接收目标位置
  3. 电机计算并移动
  4. 反馈实际位置
```

---

## 总结：为什么 0x0301 能让电机转动

1. ✅ **正确的激活码**：0x0301 启用了 Sync0 同步
2. ✅ **完整状态机**：推进到 Operation Enabled (0x1237)
3. ✅ **固定目标**：只设置一次，持续追踪
4. **✅ DC 同步**：1ms 周期性 Sync0 信号
5. **✅ CSP 模式**：0x6060 = 8 周期同步位置
6. **✅ 不使用 Free Run**：依赖 Sync0 硬件同步

这就是为什么 `./test_dc_scan 0x0301 1000000 5000` 能让电机从 5940 移动到 6840！
